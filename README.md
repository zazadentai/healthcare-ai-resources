# Healthcare AI Resources

Open-source learning resources for artificial intelligence applications in healthcare and dentistry.

## About
This repository is focused on collecting and organizing educational materials, workflows, and ideas related to:

- AI in healthcare
- AI in dentistry
- Healthcare data analysis
- Clinical workflow optimization
- Educational resources for students and clinicians

## Goals
- Share learning resources publicly
- Explore practical healthcare AI tools
- Build beginner-friendly educational content
- Support open-source learning in medicine and dentistry

## Background
Maintained by a foreign-trained dentist and McGill University MSc graduate exploring AI applications in healthcare and dentistry.
